## Status conventions

- Current implementation is described in the Stage 12 client and handover documents.
- Broader product documents may describe target or future behaviour; verify current availability against `apps/web/`, `backend/`, migrations and the handover known-limitations section.
- Stage 11 is not an unrestricted production-readiness certification. Angular tests, browser E2E, mobile acceptance and several production deployment controls remain environment or release activities.
